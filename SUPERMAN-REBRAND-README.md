# SUPERMAN Browser — rebranding update

This repository includes the original InvisiProxy LTS open-source code, with a SUPERMAN-branded interface.

Updates made:
- Homepage, header, footer and browser engine-facing names use SUPERMAN.
- Visible labels in all translations were updated, without renaming translation keys or engine identifiers.
- Legacy hero/logo/preview assets were replaced with SUPERMAN artwork.
- Existing routing, backend, Scramjet and Ultraviolet engine code was preserved.
- Original licenses, upstream notices and Credits are retained as required.

To use, copy these updated files into your own superman-browser repository, commit and redeploy in Codespaces. Browser caches and service workers may need clearing before the new assets appear.

**Note:** This is a source-level branding update; the full browser was not executed or smoke-tested here.
